A running list of things I've built, roughly newest first. Code for most of these is on [GitHub](https://github.com/reagan-nz).

## Listed Company Data Platform

Work on collecting and organizing public disclosures from A-share listed companies, with attention to source links and the differences between collecting a document and extracting structured data from it.

[GitHub](https://github.com/reagan-nz/listed-company-data-platform)

## News Topic Classification: A Preprocessing Ablation Study

Fifty controlled experiments on a four-class news classification task: five preprocessing strategies, two feature settings, and five baseline classifiers. I compared accuracy, macro-F1, and errors, finding that heavier preprocessing helped less than expected and that news-source metadata could become a misleading shortcut.

[Read the write-up]({% post_url 2026-03-20-fifty-experiments-on-news-classification %})

## Epidemic Dashboard

A dashboard visualizing epidemic data, with a Flask backend serving ECharts visualizations on the frontend.

[GitHub](https://github.com/reagan-nz/dashboard_epidemic)

## Student Information Management System

A system for managing students, classes, courses, grades, and schedules, including weighted GPA calculation. Built with Vue 3, Spring Boot, and MySQL, with search and pagination across the modules.

## Course Registration System

A desktop application for course creation, enrollment, dropping courses, and report export. Built in Java with a Swing interface, an object-oriented class design, and serialized file storage.

[GitHub](https://github.com/reagan-nz/Course_Registration_System)
