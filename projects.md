A running list of things I've built, roughly newest first. Code for most of these is on [GitHub](https://github.com/reagan-nz).

### Listed Company Data Platform
*Python, RAG, multi-agent, Playwright*

An end-to-end financial intelligence platform for A-share listed companies: collecting, cleaning, validating, storing, and vectorizing filings and market events, then answering natural-language questions over them with retrieval-augmented generation and verifiable source evidence.

[GitHub →](https://github.com/reagan-nz/listed-company-data-platform)

### News Topic Classification: A Preprocessing Ablation Study
*Python, pandas, scikit-learn, NLTK*

Studied how different preprocessing choices and metadata features affect a 4-class news classification task, running 50 controlled experiments across 5 preprocessing strategies, 2 feature settings, and 5 baseline classifiers, evaluated with accuracy, macro-F1, and confusion-matrix/error analysis.

### Epidemic Dashboard
*Flask, ECharts*

A real-time dashboard visualizing epidemic data.

[GitHub →](https://github.com/reagan-nz/dashboard_epidemic)

### Student Information Management System
*Vue 3, Spring Boot, MySQL*

A full-stack system for managing students, classes, courses, grades, and schedules, including weighted GPA calculation and basic data analysis, with a Vue frontend talking to a Spring Boot + MySQL backend.

### Course Registration System
*Java, Swing*

A desktop course registration system for admins and students, with course creation/enrollment/drop flows and report export, built with an object-oriented class design (User, Student, Admin, Course) and a Swing GUI.

[GitHub →](https://github.com/reagan-nz/Course_Registration_System)
